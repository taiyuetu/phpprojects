# CRM业务流程说明

## 核心业务流程

```
┌─────────────────────────────────────────────────────────────────┐
│                         线索生命周期                              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
                     ┌─────────────────┐
                     │  新建线索 (new)  │
                     │  陌生客户信息    │
                     └────────┬────────┘
                              │
                              ▼
                     ┌─────────────────┐
                     │ 已联系(contacted)│
                     │ 初步沟通了解需求  │
                     └────────┬────────┘
                              │
            ┌─────────────────┼─────────────────┐
            │                 │                 │
            ▼                 ▼                 ▼
   ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
   │ 有真实采购意向 │  │ 只是比价/暂无 │  │  符合流失条件 │
   │ 采购时间明确   │  │ 真实采购意愿   │  │              │
   │ 采购数量确定   │  │              │  │              │
   └───────┬───────┘  └───────┬───────┘  └───────┬───────┘
           │                  │                  │
           ▼                  ▼                  ▼
   ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
   │   转为商机     │  │  持续跟进     │  │  标记流失     │
   │  (qualified)  │  │  (contacted)  │  │   (lost)     │
   └───────┬───────┘  └───────────────┘  └───────┬───────┘
           │                                      │
           ▼                                      ▼
   ┌───────────────┐                      ┌───────────────┐
   │ 自动创建客户  │                      │ 记录流失原因  │
   │ 自动创建商机  │                      │ 可重新激活    │
   └───────────────┘                      └───────────────┘
```

## 线索状态说明

| 状态 | 含义 | 操作 |
|------|------|------|
| `new` | 新建线索，尚未联系 | 编辑、删除 |
| `contacted` | 已联系，初步沟通中 | 转商机、标记流失、编辑 |
| `qualified` | 已确认有真实意向，已转为商机 | 查看（只读） |
| `lost` | 流失，暂无机会 | 重新激活 |

## 流失原因列表

| 原因代码 | 说明 |
|----------|------|
| `no_need` | 暂无需求 |
| `competitor` | 已选竞品 |
| `budget` | 预算不足 |
| `no_match` | 需求不匹配 |
| `no_response` | 长期无响应（超过30天） |
| `project_cancel` | 项目取消 |
| `contact_lost` | 联系不上 |
| `other` | 其他原因 |

## 商机 vs 线索 vs 跟进记录

| 类型 | 定义 | 特点 | 存在位置 |
|------|------|------|----------|
| **商机** | 有真实采购意向的询价 | 有采购时间、意愿、数量 | 客户详情页 |
| **线索** | 潜在客户信息 | 尚未转化为客户 | 线索列表 |
| **跟进记录** | 比价或无采购意愿的询价 | 记录客户比价情况 | 客户详情页 |

## 数据流转

### 1. 线索转商机
```
线索 → 点击"转为商机" → 自动创建客户 → 自动创建商机 → 线索状态变为qualified
```

### 2. 线索流失
```
线索 → 点击"标记流失" → 选择流失原因 → 线索状态变为lost
```

### 3. 流失重新激活
```
已流失线索 → 点击"重新激活" → 线索状态恢复为contacted → 可继续跟进或转商机
```
