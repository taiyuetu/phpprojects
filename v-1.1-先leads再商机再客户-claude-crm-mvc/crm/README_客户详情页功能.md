# 客户详情页功能说明

## 功能概述

客户详情页现在包含以下功能：

### 1. 商机记录（Deals）
- 显示客户的所有商机
- 包括：商机标题、金额、预计成交日期、阶段状态
- 商机定义：客户有回复、真实采购时间、采购意愿、采购数量的询价

### 2. 关联线索（Leads）
- 显示与客户关联的线索信息
- 包括：线索标题、联系人、联系邮箱、来源、状态、预计价值
- 线索定义：还没有录入客户之前的潜在陌生客户信息

### 3. 跟进记录（Follow-ups）
- 记录客户的跟进情况
- 类型包括：
  - **比价询价**：客户没有真实采购意愿，只进行比价
  - **无回复**：客户无回复
  - **跟进中**：正在跟进
  - **其他**：其他情况
- 可记录：标题、描述、下一步行动、下次跟进日期

### 4. 活动记录（Activities）
- 记录电话、会议、备注等一般活动

## 数据库迁移

执行以下SQL迁移文件来添加新功能：

```bash
mysql -u root -p < database/migrate_customer_detail.sql
```

迁移内容：
1. 在 `leads` 表中添加 `customer_id` 字段，用于关联客户
2. 创建 `follow_ups` 表，用于记录跟进信息

## 文件变更

### 新增文件
- `app/models/FollowUp.php` - 跟进记录模型
- `database/migrate_customer_detail.sql` - 数据库迁移文件

### 修改文件
- `app/models/Customer.php` - 添加 `leads()` 方法获取关联线索
- `app/controllers/CustomerController.php` - 更新 `show()` 方法，添加 `addFollowUp()` 方法
- `app/views/customers/show.php` - 重新设计详情页面布局
- `app/routes.php` - 添加跟进记录路由

## 使用说明

1. **查看客户详情**：点击客户列表中的客户名称
2. **添加跟进记录**：在客户详情页的"跟进记录"区域填写表单并提交
3. **关联线索**：在线索编辑页面设置 `customer_id` 字段来关联客户
4. **添加活动记录**：在"活动记录"区域填写备注并提交

## 商机 vs 线索 vs 跟进记录

| 类型 | 定义 | 特点 |
|------|------|------|
| 商机 | 有真实采购意向的询价 | 有采购时间、意愿、数量 |
| 线索 | 潜在客户信息 | 尚未转化为客户 |
| 跟进记录 | 比价或无采购意愿的询价 | 记录客户比价情况 |
